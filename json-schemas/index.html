    JSON Schemas#

    The JSON schemas below define the input format for this task. They are generated from the Pydantic models in src/aind_physiology_fip and used to generate src/Extensions/AindPhysiologyFip.cs via Bonsai.Sgen.

    Download full schema

    The schema contains definitions for:

    • AindPhysioFipRig — hardware rig configuration
    • Session — session input parameters
